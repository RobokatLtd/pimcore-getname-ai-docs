Erste Konfiguration: Attributerkennung

Auf dieser Seite richten Sie eine Konfiguration ein, die Attributwerte aus Produktbeschreibungen liest und in den Classification Store schreibt.

Die ganze an den Dienst gesendete Beschreibung

Produktname: Kabelverschraubung M25x1,5, Polyamid, schwarz

Beschreibung: Kabelverschraubung mit metrischem Gewinde M25x1,5. Gehäuse aus Polyamid in Schwarz RAL 9005. Kabeldurchmesser 9-17 mm, Schlüsselweite 33 mm, Schutzart IP68. Halogenfrei, mit Zugentlastung. Betriebstemperatur von -40 bis 100 °C.

Das brauchen Sie: einen API-Schlüssel und einige Produkte, bei denen im Classification-Store-Feld bereits eine Gruppe aktiv ist.

Produkte brauchen eine Klassifikationsklasse

Die Konfiguration nimmt nur Produkte, die eine Klassifikationsklasse haben. Zeigt die Zählung 0 und sind die übersprungenen Produkte „ohne zugewiesene Klasse“, führen Sie zuerst die Klassenerkennung aus.

Ein leerer Umfang bedeutet die gesamte Objektklasse

Wenn Sie keinen Ordner und kein Objekt hineinziehen, umfasst die Konfiguration jedes Produkt der Objektklasse, und das Bestätigungsfenster warnt Sie davor. Prüfen Sie vor dem Start immer die Zahl aus der Zählung: So viele bezahlte Aufrufe senden Sie.

  • Classic
  • Studio

Konfiguration anlegen

Abschnitt betitelt „Konfiguration anlegen“
  1. Klicken Sie im Hauptmenü auf Datahub und dann auf den Pfeil neben Konfiguration hinzufügen. Wählen Sie getName.ai und geben Sie einen Namen ein, zum Beispiel products_attributes.
  2. Fügen Sie auf dem Reiter Verbindung Ihren API-Schlüssel ein und klicken Sie auf Verbindung testen.
  3. Lassen Sie Aufgabenart auf Attributerkennung und wählen Sie ein Erkennungsprofil. Verwenden Sie denselben Standard, aus dem die Klassen Ihrer Produkte stammen.

Aufgabe beschreiben

Abschnitt betitelt „Aufgabe beschreiben“
  1. Wählen Sie auf dem Reiter Aufgabe unter Klasse die Objektklasse Ihrer Produkte.
  2. Ziehen Sie einen Ordner aus dem Baum in den Abschnitt Produktumfang.
  3. Stellen Sie Ebene in der Hierarchie auf Nur unterste Ebene, wenn die eigentlichen Produkte ganz unten in der Hierarchie liegen. In einem Katalog ohne Varianten ändert diese Option nichts.

Festlegen, was gesendet wird

Abschnitt betitelt „Festlegen, was gesendet wird“
  1. Klicken Sie im Abschnitt An den Dienst gesendete Beschreibung auf Felder auswählen, aktivieren Sie die Felder mit der Beschreibung und den technischen Daten und klicken Sie auf Anwenden. Je mehr konkrete Daten Sie senden, desto mehr Attribute kann der Dienst lesen.
  2. Lassen Sie für die gewählten Felder Feldnamen voranstellen aktiviert.
  3. Wenn die Felder lokalisiert sind, wählen Sie Sprachen der Beschreibung. Ein Produkt wird in einer Sprache gesendet: der ersten auf der Liste, in der es alle gewählten Felder hat.

Festlegen, wohin das Ergebnis geschrieben wird

Abschnitt betitelt „Festlegen, wohin das Ergebnis geschrieben wird“
  1. Stellen Sie im Abschnitt Schreibziel den Typ auf Classification Store und wählen Sie dessen Feld unter Feld.
  2. Stellen Sie Modus auf Lücken füllen. Das Plugin sendet dann nur Produkte mit leeren Attributen und schreibt nur die leeren Attribute.
  3. Klicken Sie auf Speichern.

Mapping einrichten

Abschnitt betitelt „Mapping einrichten“
  1. Öffnen Sie den Reiter Mapping. Prüfen Sie, ob Klasse zuordnen über und Attribut zuordnen über auf name stehen. Wenn Ihre Schlüssel als KLASSE.Attribut gespeichert sind, stellen Sie Attribut zuordnen über auf nameInGroup.
  2. Klicken Sie im Abschnitt Schreibform auf Store vermessen. Die Tabelle zeigt, welche Schlüsseltypen Ihr Classification Store hat.
  3. Lassen Sie Schreiben für die Paare aktiviert, die Sie schreiben möchten. Ein nicht aktiviertes Paar wird nie geschrieben und landet stattdessen im Bericht.
  4. Klicken Sie auf Speichern.

Ein Produkt testen

Abschnitt betitelt „Ein Produkt testen“
  1. Ziehen Sie auf dem Reiter Ausführung ein Produkt in den Abschnitt Probe an einem einzelnen Produkt und klicken Sie auf Beschreibung anzeigen (kostenlos).
  2. Klicken Sie auf Dienst fragen (ein Aufruf). Sie sehen die Antwort des Dienstes so, wie sie zurückkam. Prüfen Sie, ob es zu den Attributcodes passende Schlüssel im Classification Store gibt.

Ausführen

Abschnitt betitelt „Ausführen“
  1. Klicken Sie auf Umfang zählen. Die Zählung liest die gespeicherte Konfiguration, speichern Sie Änderungen also vorher.
  2. Prüfen Sie die Zahl und die Gründe für das Überspringen und klicken Sie dann auf Durchlauf starten.
  3. Prüfen Sie im Bestätigungsfenster die Anzahl der Produkte und klicken Sie auf Ja.

Konfiguration anlegen

Abschnitt betitelt „Konfiguration anlegen“
  1. Öffnen Sie Automatisierung & Integration und dann Data Hub Konfiguration.
  2. Klicken Sie unter der Konfigurationsliste auf Neu, wählen Sie getName.ai und geben Sie einen Namen ein, zum Beispiel products_attributes.
  3. Fügen Sie auf dem Reiter Verbindung Ihren API-Schlüssel ein, klicken Sie auf Verbindung testen und wählen Sie ein Erkennungsprofil. Verwenden Sie denselben Standard, aus dem die Klassen Ihrer Produkte stammen.

Aufgabe beschreiben

Abschnitt betitelt „Aufgabe beschreiben“
  1. Öffnen Sie den Reiter Aufgabe und klicken Sie auf Attribute wählen.
  2. Wählen Sie unter Produktklasse: die Objektklasse Ihrer Produkte.
  3. Ziehen Sie einen Ordner aus dem Baum auf Datenobjekte.
  4. Stellen Sie Ebene in der Hierarchie: auf nur unterste Ebene, wenn die eigentlichen Produkte ganz unten in der Hierarchie liegen. In einem Katalog ohne Varianten ändert diese Option nichts.
  5. Wählen Sie im Abschnitt Produkte, die bereits Attributwerte haben die Option Lücken füllen. Das Plugin sendet dann nur Produkte mit leeren Attributen und schreibt nur die leeren Attribute.

Festlegen, was gesendet wird

Abschnitt betitelt „Festlegen, was gesendet wird“
  1. Lassen Sie im Abschnitt Was wir senden die Option Aus Feldern zusammengesetzter Text ausgewählt und klicken Sie auf Feld hinzufügen. Wählen Sie die Felder mit der Beschreibung und den technischen Daten. Je mehr konkrete Daten Sie senden, desto mehr Attribute kann der Dienst lesen.
  2. Wenn die Felder lokalisiert sind, wählen Sie Sprachen der Beschreibung:. Ein Produkt wird in einer Sprache gesendet: der ersten auf der Liste, in der es alle gewählten Felder hat.
  3. Geben Sie unter Vorschau für Produkt-ID: eine Produkt-ID ein und klicken Sie auf Beschreibung anzeigen.

Festlegen, wohin das Ergebnis geschrieben wird

Abschnitt betitelt „Festlegen, wohin das Ergebnis geschrieben wird“
  1. Stellen Sie im Abschnitt Ziel die Zielart: auf Classification Store und wählen Sie dessen Feld unter Feld:.
  2. Klicken Sie unten in der Ansicht auf Speichern.

Mapping einrichten

Abschnitt betitelt „Mapping einrichten“
  1. Öffnen Sie den Reiter Mapping und klicken Sie auf Classification Store prüfen. Das ist kostenlos und zeigt, welche Schlüsseltypen Ihr Classification Store hat.
  2. Prüfen Sie, ob Klasse zuordnen über: und Attribut zuordnen über: auf Name stehen. Wenn Ihre Schlüssel als KLASSE.Attribut gespeichert sind, stellen Sie Attribut zuordnen über: auf Name nach dem Gruppennamen (GRUPPE.Attribut).
  3. Lassen Sie im Abschnitt Wie Werte geschrieben werden die Paare aktiviert, die Sie schreiben möchten. Ein nicht aktiviertes Paar wird nie geschrieben und landet stattdessen im Bericht.
  4. Klicken Sie auf Speichern.

Ein Produkt testen

Abschnitt betitelt „Ein Produkt testen“
  1. Geben Sie auf dem Reiter Aufgabe im Abschnitt Test an einem Produkt eine Produkt-ID: ein und klicken Sie auf Zuordnung testen (1 bezahlter Aufruf).
  2. Gehen Sie die Tabelle durch. Jede Zeile ist ein Attribut aus der Antwort. Die Spalte Zugeordnet zeigt, ob in Pimcore ein Schlüssel gefunden wurde, und Warum nicht nennt den Grund, falls nicht.

Ausführen

Abschnitt betitelt „Ausführen“
  1. Klicken Sie auf dem Reiter Ausführung auf Neu berechnen und prüfen Sie die Zahl und die Gründe für das Überspringen.
  2. Klicken Sie auf Jetzt ausführen.
  3. Prüfen Sie im Bestätigungsfenster die Anzahl der Produkte und klicken Sie auf Jetzt ausführen.

Ergebnis prüfen

Abschnitt betitelt „Ergebnis prüfen“

Öffnen Sie einige Produkte und vergleichen Sie die Werte mit der Beschreibung. Der CSV-Bericht zeigt jedes Produkt mit seinem Ergebnis und einem etwaigen Grund für das Überspringen. Siehe Ergebnisse auswerten.
