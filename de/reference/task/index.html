Aufgabe

Auf diesem Reiter legen Sie fest, welche Produkte an den Dienst gehen, welche Beschreibung mitgeht und wohin die Antwort geschrieben wird.

Aufgabenart

Abschnitt betitelt „Aufgabenart“

Eine Konfiguration erledigt eine Aufgabe. Um Klassen und Attribute zu erkennen, legen Sie zwei Konfigurationen an.

  • Classic
  • Studio

Die Aufgabenart steht auf dem Reiter Verbindung. Eine Änderung leert das Schreibziel und die Bedingungen.

Eine neue Konfiguration fragt zuerst nach der Art: Klassifizierung wählen oder Attribute wählen. Mit Art ändern ändern Sie sie später. Dabei werden das Ziel und die Bedingungen geleert, die Beschreibung und die Verbindungseinstellungen bleiben.

Welche Ebene Sie verwenden: Eine Klassifikationsklasse wird nach unten vererbt, für die Klassenerkennung wählen Sie also meist die oberste Ebene. Attribute werden meist auf der untersten Ebene erkannt, wo die eigentlichen Produkte liegen. Ebenen dazwischen werden nur mit „alle Ebenen“ gesendet.

Bedingungen

Abschnitt betitelt „Bedingungen“

Klicken Sie auf Bedingung hinzufügen und wählen Sie dann ein Feld, einen Operator und einen Wert. So können Sie zum Beispiel einen Lieferanten oder Produkte mit einem leeren Feld auswählen.

Alle Bedingungen müssen gleichzeitig erfüllt sein. Wenn ein Feld einen von mehreren Werten haben darf, verwenden Sie den Operator ist eines von. Eine Bedingung ohne Wert stoppt die Zählung, bis Sie den Wert eintragen.

Produkte, die bereits ein Ergebnis haben

Abschnitt betitelt „Produkte, die bereits ein Ergebnis haben“

Diese Einstellung wirkt sich am stärksten auf die Kosten aus. Studio hat dafür einen eigenen Abschnitt. In Classic ist es das Feld Modus im Abschnitt Schreibziel.

Die vorhandene Klasse überschreiben Alles überschreiben jedes Produkt im Umfang die gelieferte Klasse

Die neue Klasse deaktiviert die bisherige Gruppe, und Pimcore behält Daten nur für die aktive Gruppe.

Was gesendet wird

Abschnitt betitelt „Was gesendet wird“

Studio nennt diesen Abschnitt Was wir senden, Classic An den Dienst gesendete Beschreibung.

Quelle der Beschreibung

Abschnitt betitelt „Quelle der Beschreibung“

Classic sendet immer aus Feldern zusammengesetzten Text. Bei der Attributerkennung können Sie in Studio auch eine Adresse wählen:

Quelle in Studio Was passiert
Aus Feldern zusammengesetzter Text Die gewählten Felder ergeben eine Beschreibung
Adresse einer Webseite Ein Feld enthält die Adresse, und der Dienst öffnet die Seite selbst
Adresse einer Datei Ein Feld enthält die Adresse eines PDF oder eines anderen Dokuments, und der Dienst ruft es selbst ab

Die Adresse muss aus dem Internet erreichbar sein. Ein Pfad im Pimcore-Baum funktioniert nicht, und der Dienst antwortet mit PDF_READ_ERROR.

Beschreibungsfelder

Abschnitt betitelt „Beschreibungsfelder“

Klicken Sie in Studio auf Feld hinzufügen oder in Classic auf Felder auswählen. Mit den Pfeilen ändern Sie die Reihenfolge.

  • Feldnamen voranstellen sendet den Wert als Bezeichnung: Wert.
  • Bezeichnung in der Beschreibung ersetzt den Feldtitel. Bleibt sie leer, wird der Feldtitel verwendet.
  • lokalisiert kennzeichnet ein Feld, das in der gewählten Beschreibungssprache gelesen wird.
  • Eine rote Markierung bedeutet, dass das Feld nicht mehr in der Objektklasse ist. Zählung und Durchlauf stoppen, bis Sie es korrigieren oder entfernen.

Sie können einfache Felder, Object Bricks, Blöcke, Feldsammlungen und Felder verknüpfter Objekte wählen. Für verknüpfte Felder gilt:

  • Eine Relation zu mehreren Objekten ergibt eine Liste mit einer Zeile pro Objekt.
  • Unveröffentlichte verknüpfte Objekte werden übersprungen.
  • Über eine Relation zu derselben Objektklasse, etwa bei Zubehör, sind nur einfache Felder verfügbar.
  • Classic
  • Studio

In der Feldauswahl ist jede Relation eine eingeklappte Gruppe. Klicken Sie auf eine Gruppe, um sie zu öffnen. Filter finden Sie im Spaltenmenü.

Um die Felder verknüpfter Objekte anzuzeigen, wählen Sie über der Liste unter Felder verknüpfter Objekte eine Relation.

In Datei exportieren speichert die Feldliste und die Sprachen in einer JSON-Datei, ohne den API-Schlüssel. Aus Datei importieren ersetzt sie in der geöffneten Konfiguration. Speichern Sie die Konfiguration nach dem Import.

Sprachen der Beschreibung

Abschnitt betitelt „Sprachen der Beschreibung“

Das betrifft lokalisierte Felder. Die gewählte Reihenfolge ist die Ersatzreihenfolge: Ein Produkt wird in der ersten Sprache gesendet, in der es alle gewählten lokalisierten Felder hat. Hat keine Sprache alle, wählt das Plugin die mit den meisten.

Die gesamte Beschreibung eines Produkts ist in einer Sprache, und der Dienst erfährt, in welcher. Eine leere Liste bedeutet die Standardsprache der Instanz. Der in Pimcore eingestellte Sprach-Fallback spielt hier keine Rolle.

Der Dienst erhält die gewählte Sprache auch dann, wenn die Felder nicht lokalisiert sind. Wenn Ihre Beschreibungen in einer anderen Sprache als der Standardsprache der Instanz verfasst sind, wählen Sie sie auf der Liste aus.

Produktcode

Abschnitt betitelt „Produktcode“

Dieses Feld ist optional und wirkt bei Attributen. Es teilt dem Dienst mit, um welches Produkt es in der Antwort gehen soll, wenn der Text mehrere Produkte beschreibt, etwa ein PDF-Datenblatt für eine ganze Serie. Das Feld heißt Feld mit dem Produktcode.

Beschreibungsvorschau

Abschnitt betitelt „Beschreibungsvorschau“

Die Vorschau ist kostenlos. Sie zeigt den Text, seine Länge und seine Sprache für ein Produkt.

  • Classic
  • Studio

Ziehen Sie auf dem Reiter Ausführung ein Produkt in den Abschnitt Probe an einem einzelnen Produkt und klicken Sie auf Beschreibung anzeigen (kostenlos). Die Vorschau setzt die Beschreibung aus der gespeicherten Konfiguration zusammen.

Geben Sie die ID unter Vorschau für Produkt-ID: ein und klicken Sie auf Beschreibung anzeigen.

Schreibziel

Abschnitt betitelt „Schreibziel“

Beide Panels bieten dieselben Ziele:

Aufgabenart Profil Studio Classic
Klassifikationsklasse ein Standard wie ETIM Classification Store auf der Klasse Classification Store
Klassifikationsklasse Ihr eigener Kategoriebaum Relation zu einem Kategorieobjekt Relation
Attribute ein Standard wie ETIM Classification Store Classification Store

In Studio zeigt die Liste außerdem ausgegraute Einträge mit dem Zusatz „(später)“: eine Vorschlagstabelle, einen Object Brick, ein Textfeld und eine Feldsammlung. Diese Ziele lassen sich noch nicht wählen.

Feld ist ein Feld der gewählten Art auf der Objektklasse.

Zweiter Treffer in ein Textfeld

Abschnitt betitelt „Zweiter Treffer in ein Textfeld“

Diese Einstellung ist optional und wirkt bei der Klassenerkennung. Das Plugin schreibt eine Zeile mit der nächstbesten Alternative in dieses Feld, und jeder Durchlauf überschreibt sie. So sehen Sie, bei welchen Produkten der Dienst unsicher war. Der Modus Nur berichten, Daten nicht anfassen braucht dieses Feld.

Test an einem Produkt

Abschnitt betitelt „Test an einem Produkt“

Der Test kostet einen Aufruf und schreibt nichts. Er verwendet die gespeicherte Konfiguration, speichern Sie also vorher. Ein weiterer Aufruf für dasselbe Produkt kann eine leicht andere Attributmenge liefern, der Test garantiert also nicht genau dasselbe Ergebnis im Durchlauf.

  • Classic
  • Studio

Der Abschnitt Probe an einem einzelnen Produkt liegt auf dem Reiter Ausführung. Sie ziehen ein Produkt aus dem Baum hinein. Das Ergebnis ist die Antwort des Dienstes, so wie sie zurückkam.

Der Abschnitt Test an einem Produkt liegt unter dem Abschnitt Ziel. Die Tabelle zeigt, was zurückkam und was wozu passte, und die Spalte Warum nicht nennt den Grund.
