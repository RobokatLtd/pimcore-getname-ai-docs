Bevor Sie beginnen

Was bereitstehen muss

Abschnitt betitelt „Was bereitstehen muss“
  • Das installierte Plugin und ein laufender Hintergrund-Worker. Ohne Worker bleibt ein Durchlauf dauerhaft im Status „läuft“. Siehe Installation.
  • Ein API-Schlüssel von getName.ai. Das Plugin spricht den Dienst über dessen API an. Laut der Website von getName.ai funktioniert der kostenlose Tarif (50 Anfragen pro Monat) nur im Browser, das Plugin braucht also einen Tarif mit API-Zugang.
  • Eine Objektklasse mit Feldern, die das Produkt beschreiben. Der Dienst erkennt ein Produkt nur anhand dessen, was Sie ihm senden.
  • Ein Ort für das Ergebnis. Bei einem Standard wie ETIM ist das ein Classification-Store-Feld auf der Objektklasse. Bei Ihrem eigenen Kategoriebaum ist es ein Relationsfeld, das auf Kategorieobjekte zeigt.
  • Zugriff auf die Konfiguration. Administratoren haben ihn von Anfang an. Andere Benutzer brauchen die Berechtigungen, die unter Protokolle und Berechtigungen beschrieben sind.

Das Plugin legt im Classification Store keine Gruppen oder Schlüssel an. Liefert der Dienst einen Code, den es in Pimcore nicht gibt, wird das Produkt oder Attribut übersprungen, und der Grund steht im Bericht.

Zwei verschiedene Klassen

Eine Objektklasse ist die Definition von Datenobjekten in Pimcore, etwa Product. Eine Klassifikationsklasse ist der Platz eines Produkts in einem System wie ETIM, etwa EC000441 Kabelverschraubung. Das Wort „Klasse“ allein bedeutet in dieser Anleitung immer die Klassifikationsklasse. Die Objektklasse wählen Sie im Panel unter Klasse (Classic) oder Produktklasse: (Studio).

Warum Sie meist zwei Konfigurationen brauchen

Abschnitt betitelt „Warum Sie meist zwei Konfigurationen brauchen“

Eine Konfiguration erledigt eine Aufgabe: Sie erkennt entweder die Klassifikationsklasse oder die Attribute.

Der Dienst erkennt Attribute innerhalb einer Klassifikationsklasse, denn diese legt fest, welche Attribute ein Produkt haben kann. Eine Attributkonfiguration nimmt deshalb nur Produkte, die bereits eine Klassifikationsklasse haben. Wenn Ihre Produkte noch keine haben, führen Sie zuerst eine Klassenkonfiguration aus.

Sicher anfangen

Abschnitt betitelt „Sicher anfangen“
  1. Wählen Sie einen Ordner mit einigen unterschiedlichen Produkten.
  2. Sehen Sie sich die Beschreibung eines Produkts an. Das ist kostenlos.
  3. Testen Sie ein Produkt. Das ist ein Aufruf, und am Produkt wird nichts geschrieben.
  4. Führen Sie die Konfiguration auf diesem Ordner aus und prüfen Sie die Produkte in Pimcore.
  5. Erweitern Sie erst dann den Umfang.
