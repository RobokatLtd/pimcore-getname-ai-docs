Erste Konfiguration: Klassenerkennung

Auf dieser Seite richten Sie eine Konfiguration ein, die Produkten eine Klassifikationsklasse aus einem Standard wie ETIM gibt und sie in den Classification Store schreibt. Gemeint ist nicht die Objektklasse in Pimcore, die wählen Sie separat.

Das brauchen Sie: einen API-Schlüssel, eine Objektklasse mit einem Classification-Store-Feld und einen Ordner mit einigen Produkten, die noch keine Klassifikationsklasse haben. Der Classification Store sollte bereits Gruppen für die Klassen des gewählten Standards enthalten.

Wenn Sie Kategorien aus Ihrem eigenen Baum erkennen lassen, gehen Sie genauso vor, wählen aber eine Relation als Ziel. Siehe Schreibziel.

Ein leerer Umfang bedeutet die gesamte Objektklasse

Wenn Sie keinen Ordner und kein Objekt hineinziehen, umfasst die Konfiguration jedes Produkt der Objektklasse, und das Bestätigungsfenster warnt Sie davor. Prüfen Sie vor dem Start immer die Zahl aus der Zählung: So viele bezahlte Aufrufe senden Sie.

  • Studio

Konfiguration anlegen

Abschnitt betitelt „Konfiguration anlegen“
  1. Klicken Sie im Hauptmenü auf Datahub.
  2. Klicken Sie auf den Pfeil neben Konfiguration hinzufügen, wählen Sie getName.ai und geben Sie einen Namen ein, zum Beispiel products_classification.

Mit dem Dienst verbinden

Abschnitt betitelt „Mit dem Dienst verbinden“
  1. Öffnen Sie den Reiter Verbindung und fügen Sie Ihren Schlüssel unter API-Schlüssel ein.
  2. Klicken Sie auf Verbindung testen. Sie sehen eine Meldung, dass die Verbindung funktioniert, zusammen mit den Angaben zu Ihrem Abonnement.
  3. Stellen Sie Aufgabenart auf Klassenerkennung. Eine neue Konfiguration beginnt mit der Attributerkennung.
  4. Wählen Sie unter Erkennungsprofil ein Profil, zum Beispiel ETIM in der benötigten Sprache.

Aufgabe beschreiben

Abschnitt betitelt „Aufgabe beschreiben“
  1. Öffnen Sie den Reiter Aufgabe und wählen Sie unter Klasse die Objektklasse Ihrer Produkte.
  2. Ziehen Sie einen Ordner aus dem Objektbaum in den Abschnitt Produktumfang. Aktivieren Sie Mit Unterelementen, wenn Unterordner einbezogen werden sollen.
  3. Stellen Sie Ebene in der Hierarchie auf Nur oberste Ebene, wenn die Klassifikationsklasse an Varianten vererbt werden soll. In einem Katalog ohne Varianten ändert diese Option nichts.

Festlegen, was gesendet wird

Abschnitt betitelt „Festlegen, was gesendet wird“
  1. Klicken Sie im Abschnitt An den Dienst gesendete Beschreibung auf Felder auswählen, aktivieren Sie die Felder, die das Produkt beschreiben, etwa Name und Beschreibung, und klicken Sie auf Anwenden.
  2. Lassen Sie für diese Felder Feldnamen voranstellen aktiviert. So erfährt der Dienst, was jeder Wert bedeutet.

Festlegen, wohin das Ergebnis geschrieben wird

Abschnitt betitelt „Festlegen, wohin das Ergebnis geschrieben wird“
  1. Stellen Sie im Abschnitt Schreibziel den Typ auf Classification Store.
  2. Wählen Sie unter Feld das Classification-Store-Feld der Objektklasse.
  3. Lassen Sie unter Modus die Option Produkte mit gefülltem Schreibziel überspringen ausgewählt.
  4. Klicken Sie auf Speichern.
  5. Prüfen Sie auf dem Reiter Mapping, ob Klasse zuordnen über auf name steht. Bei Standards steht der Klassencode meist im Gruppennamen.

Ein Produkt testen

Abschnitt betitelt „Ein Produkt testen“
  1. Öffnen Sie den Reiter Ausführung und ziehen Sie ein Produkt aus dem Baum in den Abschnitt Probe an einem einzelnen Produkt.
  2. Klicken Sie auf Beschreibung anzeigen (kostenlos). Prüfen Sie, ob ein Mensch das Produkt anhand dieses Textes erkennen könnte.
  3. Klicken Sie auf Dienst fragen (ein Aufruf). Sie sehen die Antwort des Dienstes so, wie sie zurückkam. Am Produkt wird nichts geschrieben.

Prüfen Sie, ob es zum Code im Feld id eine passende Gruppe im Classification Store gibt.

Ausführen

Abschnitt betitelt „Ausführen“
  1. Klicken Sie im Abschnitt Produktumfang auf Umfang zählen. Diese Zahl ist die Anzahl der bezahlten Aufrufe. Die Zählung liest die gespeicherte Konfiguration, speichern Sie Änderungen also vorher.
  2. Prüfen Sie, was übersprungen wurde. Mit Produkte anzeigen sehen Sie die Produkte.
  3. Klicken Sie auf Durchlauf starten.
  4. Prüfen Sie im Bestätigungsfenster die Anzahl der Produkte und klicken Sie auf Ja. Sie können die Ansicht schließen, der Durchlauf läuft weiter.

Konfiguration anlegen

Abschnitt betitelt „Konfiguration anlegen“
  1. Öffnen Sie Automatisierung & Integration und dann Data Hub Konfiguration.
  2. Klicken Sie unter der Konfigurationsliste auf Neu, wählen Sie getName.ai und geben Sie einen Namen ein, zum Beispiel products_classification.

Mit dem Dienst verbinden

Abschnitt betitelt „Mit dem Dienst verbinden“
  1. Öffnen Sie den Reiter Verbindung und fügen Sie Ihren Schlüssel unter API-Schlüssel ein.
  2. Klicken Sie auf Verbindung testen. Der Status wechselt auf „verbunden“, und die Karte Abonnement erscheint.
  3. Wählen Sie unter Erkennungsprofil ein Profil, zum Beispiel ETIM in der benötigten Sprache.

Aufgabe beschreiben

Abschnitt betitelt „Aufgabe beschreiben“
  1. Öffnen Sie den Reiter Aufgabe und klicken Sie auf Klassifizierung wählen.
  2. Wählen Sie unter Produktklasse: die Objektklasse Ihrer Produkte.
  3. Ziehen Sie einen Ordner aus dem Objektbaum auf Datenobjekte. Aktivieren Sie Mit Unterelementen, wenn Unterordner einbezogen werden sollen.
  4. Stellen Sie Ebene in der Hierarchie: auf nur oberste Ebene, wenn die Klassifikationsklasse an Varianten vererbt werden soll. In einem Katalog ohne Varianten ändert diese Option nichts.
  5. Lassen Sie im Abschnitt Produkte, die bereits eine Klasse haben die Option Überspringen ausgewählt.

Festlegen, was gesendet wird

Abschnitt betitelt „Festlegen, was gesendet wird“
  1. Klicken Sie im Abschnitt Was wir senden auf Feld hinzufügen und wählen Sie die Felder, die das Produkt beschreiben, etwa Name und Beschreibung.
  2. Lassen Sie Feldnamen voranstellen aktiviert. So erfährt der Dienst, was jeder Wert bedeutet.
  3. Geben Sie unter Vorschau für Produkt-ID: eine Produkt-ID ein und klicken Sie auf Beschreibung anzeigen. Prüfen Sie, ob ein Mensch das Produkt anhand dieses Textes erkennen könnte. Die Vorschau ist kostenlos.

Festlegen, wohin das Ergebnis geschrieben wird

Abschnitt betitelt „Festlegen, wohin das Ergebnis geschrieben wird“
  1. Stellen Sie im Abschnitt Ziel die Zielart: auf Classification Store auf der Klasse.
  2. Wählen Sie unter Feld: das Classification-Store-Feld der Objektklasse.
  3. Klicken Sie unten in der Ansicht auf Speichern. Der Reiter Mapping erscheint, sobald Sie gespeichert haben.
  4. Prüfen Sie auf dem Reiter Mapping, ob Klasse zuordnen über: auf Name steht. Bei Standards steht der Klassencode meist im Gruppennamen. Neben der Einstellung sehen Sie einen Beispielwert aus Ihrer Installation.

Ein Produkt testen

Abschnitt betitelt „Ein Produkt testen“
  1. Gehen Sie zurück auf den Reiter Aufgabe, in den Abschnitt Test an einem Produkt.
  2. Geben Sie eine Produkt-ID: ein und klicken Sie auf Zuordnung testen (1 bezahlter Aufruf). Am Produkt wird nichts geschrieben.

In der Ergebnistabelle sollte die Spalte Zugeordnet die Übereinstimmung bestätigen und In Pimcore die richtige Gruppe zeigen. Falls nicht, lesen Sie die Spalte Warum nicht und die Seite Ergebnisse auswerten.

Ausführen

Abschnitt betitelt „Ausführen“
  1. Öffnen Sie den Reiter Ausführung und klicken Sie im Abschnitt Wie viele Produkte auf Neu berechnen. Diese Zahl ist die Anzahl der bezahlten Aufrufe.
  2. Prüfen Sie, was übersprungen wurde. Mit Liste anzeigen sehen Sie die Produkte.
  3. Klicken Sie auf Jetzt ausführen.
  4. Prüfen Sie im Bestätigungsfenster die Anzahl der Produkte und klicken Sie auf Jetzt ausführen. Sie können die Ansicht schließen, der Durchlauf läuft weiter.

Ergebnis prüfen

Abschnitt betitelt „Ergebnis prüfen“

Öffnen Sie einige Produkte in Pimcore. Im Classification-Store-Feld sollte die Gruppe der erkannten Klasse aktiviert sein. Wenn das Ergebnis stimmt, erweitern Sie den Umfang auf dem Reiter Aufgabe und führen Sie die Konfiguration erneut aus. Beim Überspringen zahlen Sie für Produkte, die bereits eine Klasse haben, nicht noch einmal.
