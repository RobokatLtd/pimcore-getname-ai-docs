---
title: Glossary
description: Terms used in this guide and what they are called on the screens of both panels.
---

:::note[Two different classes]
An **object class** is a definition of data objects in Pimcore, for example `Product`. A **classification class** is a product's place in a system such as ETIM, for example `EC000441 Cable gland`. In this guide, "class" on its own always means a classification class. In the panel, you choose the object class under **Product class in Pimcore**.
:::

| Term | What it means | On screen |
|---|---|---|
| Attribute | one property of a classification class, such as `EF001758 Thread type` | a key in Pimcore |
| Call | one paid request to the service, one per product | |
| Class, classification class | a product's place in a classification system, such as `EC000441 Cable gland` in ETIM | **Class recognition**, **Map the class by** |
| Class recognition | the task that gives a product a classification class | Studio: **Classification**; Classic: **Class recognition** |
| Attribute recognition | the task that reads attribute values | Studio: **Attributes**; Classic: **Attribute recognition** |
| Classification Store | the Pimcore dictionary of groups and keys | Studio: **Classification attribute set**; Classic: **Classification store** |
| Data Hub | the Pimcore module where you create configurations | Studio: **Data Hub Configuration**; Classic: **Datahub** |
| Description | the text assembled from the chosen fields and sent for one product | Studio: **What we send**; Classic: **Description sent to the service** |
| Group | a classification class stored in the Classification Store; active on a product, it means the product has that class | |
| Key | one attribute in a group, with a type and, for selections, a list of values | |
| Mapping | pointing at the Pimcore field that holds the code the service returns | **Mapping** |
| Object class | the Pimcore class, a definition of data objects, that the configuration takes products from; not to be confused with a classification class | **Product class in Pimcore** |
| Recognition profile | a classification system in one version and language, or a profile from your own category tree | **Recognition profile** |
| Run | one execution of a configuration, processed in chunks through the queue | Studio: **Run now**; Classic: **Start run** |
| Run mode | what to do with products that already have a result | Studio: the **Products that already have…** section; Classic: **Run mode** |
| Scope | the products the configuration will send | Studio: **How many products**; Classic: **Product scope** |
| Worker | a process that keeps running and handles the queue of runs | |
| Write target | where the answer ends up | Studio: **Target**; Classic: **Write target** |
