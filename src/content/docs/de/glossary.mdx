---
title: Glossar
description: Die in dieser Anleitung verwendeten Begriffe und wie sie in den Ansichten beider Panels heißen.
---

:::note[Zwei verschiedene Klassen]
Eine **Objektklasse** ist die Definition von Datenobjekten in Pimcore, etwa `Product`. Eine **Klassifikationsklasse** ist der Platz eines Produkts in einem System wie ETIM, etwa `EC000441 Kabelverschraubung`. Das Wort „Klasse“ allein bedeutet in dieser Anleitung immer die Klassifikationsklasse. Die Objektklasse wählen Sie im Panel unter **Produktklasse in Pimcore**.
:::

| Begriff | Bedeutung | In der Ansicht |
|---|---|---|
| Attribut | eine Eigenschaft einer Klassifikationsklasse, etwa `EF001758 Gewindeart` | ein Schlüssel in Pimcore |
| Attributerkennung | die Aufgabe, die Attributwerte liest | Studio: **Attribute**; Classic: **Attributerkennung** |
| Aufruf | eine bezahlte Anfrage an den Dienst, eine pro Produkt | |
| Beschreibung | der aus den gewählten Feldern zusammengesetzte Text, der für ein Produkt gesendet wird | Studio: **Was wir senden**; Classic: **An den Dienst gesendete Beschreibung** |
| Classification Store | das Pimcore-Wörterbuch aus Gruppen und Schlüsseln | Studio und Classic: **Classification Store** |
| Data Hub | das Pimcore-Modul, in dem Sie Konfigurationen anlegen | Studio: **Data Hub Konfiguration**; Classic: **Datahub** |
| Durchlauf | eine Ausführung einer Konfiguration, in Paketen über die Warteschlange verarbeitet | Studio: **Jetzt ausführen**; Classic: **Durchlauf starten** |
| Erkennungsprofil | ein Klassifikationssystem in einer Version und Sprache oder ein Profil aus Ihrem eigenen Kategoriebaum | **Erkennungsprofil** |
| Gruppe | eine im Classification Store gespeicherte Klassifikationsklasse; ist sie auf einem Produkt aktiv, hat das Produkt diese Klasse | |
| Klasse, Klassifikationsklasse | der Platz eines Produkts in einem Klassifikationssystem, etwa `EC000441 Kabelverschraubung` in ETIM | **Klassenerkennung**, **Klasse zuordnen über** |
| Klassenerkennung | die Aufgabe, die einem Produkt eine Klassifikationsklasse gibt | Studio: **Klassifizierung**; Classic: **Klassenerkennung** |
| Mapping | der Verweis auf das Pimcore-Feld, das den vom Dienst gelieferten Code enthält | **Mapping** |
| Modus | was mit Produkten geschieht, die bereits ein Ergebnis haben | Studio: Abschnitte **Produkte, die bereits eine Klasse haben** und **Produkte, die bereits Attributwerte haben**; Classic: **Modus** |
| Objektklasse | die Pimcore-Klasse, also die Definition der Datenobjekte, aus denen die Konfiguration Produkte nimmt; nicht zu verwechseln mit einer Klassifikationsklasse | **Produktklasse in Pimcore** |
| Schlüssel | ein Attribut in einer Gruppe, mit einem Typ und, bei Auswahlen, einer Werteliste | |
| Schreibziel | wo die Antwort landet | Studio: **Ziel**; Classic: **Schreibziel** |
| Umfang | die Produkte, die die Konfiguration senden wird | Studio: **Wie viele Produkte**; Classic: **Produktumfang** |
| Worker | ein dauerhaft laufender Prozess, der die Warteschlange der Durchläufe abarbeitet | |
