## Protokolle

Der Reiter **Protokolle** zeigt das Application Log von Pimcore, eingeschränkt auf diese Konfiguration, also auf die Komponente `GETNAME-AI configuration_name`.

Der CSV-Bericht wird aus diesen Einträgen erstellt. Die Komponente lässt sich auf diesem Reiter nicht ändern, von hier aus können Sie also nicht die Durchläufe einer anderen Konfiguration durchsehen.

## Berechtigungen

Ein Benutzer ohne Administratorrechte braucht drei Dinge:

1. die Berechtigung für die Data-Hub-Konfiguration (`plugin_datahub_config`),
2. die Berechtigung für den getName.ai-Typ (`plugin_datahub_adapter_getNameAi`),
3. einen Eintrag in der Liste **Berechtigungen** dieser Konfiguration, für sich selbst oder für die eigene Rolle.

Eine leere Liste bedeutet, dass nur Administratoren die Konfiguration öffnen können.

In der Liste aktivieren Sie, was diese Person oder Rolle tun darf. Lesezugriff allein erlaubt keine Ausführung:

| Aktion | Erforderlicher Zugriff |
|---|---|
| Ausführungsstatus, Bericht, Verlauf | Lesen (`read`) |
| Test an einem Produkt, Durchlauf, Abbrechen, Verlauf löschen | Aktualisieren (`update`) |

:::caution[API-Schlüssel]
Jeder, der eine Konfiguration öffnen kann, kann ihren API-Schlüssel lesen. Die Liste der Berechtigungen ist die einzige Stelle, an der sich der Zugriff darauf einschränken lässt.
:::
